# Couple Party — logo

**Ide:** huruf C memeluk P yang sedikit bersandar ke dalam — dua orang, satu pelukan. Dibangun dari bentuk dasar Memphis (cincin tebal, batang, bulatan).

## File
- `final-symbol.svg` — monogram warna (C Brilliant Rose, P tinta). Versi `-black`, `-white` untuk satu warna / latar gelap.
- `final-horizontal.svg` — monogram + wordmark "COUPLE PARTY" (Dela Gothic One, sudah dijadikan path). Versi `-black`, `-white`.
- `app-icon.svg`, `icon-only.svg` — ikon di tile Electric Green. `adaptive-foreground.svg` + `adaptive-background.svg` untuk ikon adaptif Android.
- `splash.svg` — splash 2732² di latar Pastel Petal.
- Semua dibangun ulang dengan `python build_logo.py`.

## Aturan
- Ruang kosong minimal = tebal cincin C (36/256 lebar simbol) di semua sisi.
- Ukuran minimum: simbol 16 px (lubang P mulai menutup di bawah itu); lockup horizontal 120 px lebar.
- Di latar gelap pakai versi `-white` atau C rose + P putih.
- Jangan: memutar seluruh logo, meluruskan P (kemiringan −8° itu bagian dari ide), mengganti font wordmark, memberi bayangan/gradien.

Font: Dela Gothic One (SIL Open Font License, aman untuk logo). Cek merek dagang profesional belum dilakukan.
